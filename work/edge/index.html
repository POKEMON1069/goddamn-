Case 04 — Identity & web

Edge

An identity for an architecture practice whose best asset was not photography — it was the discipline of its own drawing sheets.

Demonstration case study — fictional client

Client
Fictional brief, written for this build
Sector
Architecture, built environment
Scope
Wordmark, grid system, website, templates
Team
Two designers, one engineer
Modelled window
12 weeks
01

Context

A ten-person practice with three completed buildings and a fourth under construction. The work was precise; the website was a template that placed every photograph in the same rectangle. Visitors could not tell whether they were looking at a house, a gallery or a feasibility study.

The practice had no appetite for a "brand voice". What it did have was a house style for drawings: a visible structural grid, dimension lines in a single red, and annotations in a narrow technical hand. The identity was already on the drawing board.

Constraints

Inconsistent photography. No video budget. A non-technical studio manager must edit it.

02

Constraint

The real limits

  • Imagery. Photographs came from three different photographers with incompatible colour treatment.
  • Editing. Project pages had to be editable in a browser form, with no markup knowledge required.
  • Budget. No commissioning new photography in the first phase.
  • Language. The practice works in two languages; any typographic system had to survive both.
03

Decisions

The grid is the logo.

Rather than a symbol, the identity is a visible twelve-column structure with a fixed margin rule, reproduced on the site and on stationery. Trade-off: less portable as a mark — it cannot be embroidered on a shirt — but instantly recognisable as a system rather than a shape.

Type before photography.

The home page leads with the practice's position, not a hero image; photographs appear at project scale, where they can be judged. Trade-off: less immediate visual impact, and a harder sell internally, but the inconsistent photography stops undermining the practice.

One accent, only for measurement.

Vermilion appears exclusively on dimensions, dates and status — the information an architect would mark in red on a drawing. Trade-off: the palette reads austere in marketing contexts; for this practice, austerity is the message.

04

Craft

System pieces

  • A type scale in which every size is a multiple of the baseline grid, so captions align across columns.
  • Image treatment that neutralises colour casts and crops to consistent architectural axes.
  • Caption pattern: project, location, year, area — the same four facts in the same order on every page.
  • An A3 project sheet template generated from the same content model, so print and web never drift.
  • Bilingual type testing at the wireframe stage, not after launch.

What we removed

Carousels, a news section with no news, and a "philosophy" page of abstract statements. The practice's own drawings were more articulate than the copy that had been written to replace them.

05 — Signals

What we would measure.

Written brief, no claimed results. These are the signals that would show whether an identity built from a drawing convention actually travelled.

  • S1

    Enquiries that name the work

    Messages that reference a specific project, rather than a generic enquiry form.

  • S2

    Depth into project pages

    Whether visitors move from the index into individual buildings.

  • S3

    Studio manager edit time

    Minutes to publish a new project without contacting us.

  • S4

    Print requests

    Project sheets downloaded or printed by clients and collaborators.
